# Codec configuration design (planned: M5b -> M6)

Implement in order:
1. Per-sink registry settings (`Parameters\Devices\<addr>`) and global defaults: codec priority, SBC rate/channel mode/blocks/subbands/allocation/bitpool, AAC rate/channels/bitrate/VBR. Done: the `CodecPreference*` values for codec priority, SBC bitpool/blocks/subbands/allocation, the AAC bitrate and the endpoint rate/channel mode (sink key over the global default, restored at device start). The endpoint preference narrows the render formats in place; AAC rate/channels and VBR are not stored: the stream follows the endpoint format and VBR stays off.
2. Preference-aware `SbcConfig`/`AacConfig` selection with supported-value fallback. Done: `CodecPreferenceSbcBitpool` caps the selector's request and `CodecPreferenceAacBitrate` the AAC bitrate, both clamped to the sink's advertised range inside the shared selector, and `CodecTests` covers the clamps and that every bitpool still fits one RTP payload. A parameter change keeps the codec, so the signaling work item applies it in place: the encoder stops, SUSPEND brings the SEP to Open, RECONFIGURE carries the configuration the selector rebuilds from the selected SEP's advertised capabilities, and START resumes. A rejected command, or a sink-configured stream whose capabilities are unknown, falls back to close-and-rediscover. A stored block length, subband count or allocation pins the frame shape; one the sink does not advertise falls back to the selector's own order. A codec or endpoint format the sink does not advertise is refused instead of stored, and the endpoint only lists formats the sink covers. Each field stands on its own: there are no named combinations to keep in sync with a stored value.
3. Config IOCTLs and desktop UI (`OpenA2dpConfig.exe`) for device, codec and parameters. A codec change CLOSEs and rediscovers an active stream immediately (no sink reconnect); parameter changes that keep the codec use SUSPEND/RECONFIGURE/START. Done: the window lists the sinks (`tools/OpenA2dpConfig`), refreshes `GET_STATUS` on a timer, shows the session, the sink formats, the MTU ceiling and the endpoint fallback, and stores the codec and endpoint settings through `SET_PREFERENCE`; it reads the preference back after every apply, so a refused value stays visible. `OpenA2dpCtl` remains the script path.
4. Multi-rate ACX: 44.1/48 kHz and selected mono, matching the negotiated format or resampling; last to protect the validated audio path. Done: the endpoint lists 16-bit PCM at 44.1 and 48 kHz, mono and stereo; the stream Windows opens sets `PinSampleRate`/`PinChannels` for the PCM/position math and the encoder, and SBC/AAC negotiation prefers that rate and channel count. Resampling for a sink that lacks the pin format remains; a stored rate now changes the endpoint default and its format list without a device restart.
5. M6: finish UI and clean install/uninstall restoring `BthA2dp.sys`.
