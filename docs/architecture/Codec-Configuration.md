# Codec configuration design (planned: M5b -> M6)

Implement in order:
1. Per-sink registry settings (`Parameters\Devices\<addr>`) and global defaults: codec priority, SBC rate/channel mode/blocks/subbands/allocation/bitpool, AAC rate/channels/bitrate/VBR. Done: the `CodecPreference*` values (sink key over the global default, restored at device start); the remaining per-codec fields are not stored yet.
2. Preference-aware `SbcConfig`/`AacConfig` selection with supported-value fallback. Done: `CodecPreferenceSbcBitpool` caps the selector's request and `CodecPreferenceAacBitrate` the AAC bitrate, both clamped to the sink's advertised range inside the shared selector, and `CodecTests` covers the clamps and that every bitpool still fits one RTP payload. A parameter change keeps the codec, so the signaling work item applies it in place: the encoder stops, SUSPEND brings the SEP to Open, RECONFIGURE carries the configuration the selector rebuilds from the selected SEP's advertised capabilities, and START resumes. A rejected command, or a sink-configured stream whose capabilities are unknown, falls back to close-and-rediscover. Sample rate, channel mode, blocks, subbands, allocation and named presets remain.
3. Config IOCTLs and desktop UI (`OpenA2dpConfig.exe`) for device, codec, presets and parameters. A codec change CLOSEs and rediscovers an active stream immediately (no sink reconnect); parameter changes that keep the codec use SUSPEND/RECONFIGURE/START. Existing CLI status/codec preference remains the interim test path.
4. Multi-rate ACX: 44.1/48 kHz and selected mono, matching the negotiated format or resampling; last to protect the validated audio path.
5. M6: finish UI and clean install/uninstall restoring `BthA2dp.sys`.
