# Codec configuration design (planned: M5b -> M6)

Implement in order:
1. Per-sink registry settings (`Parameters\Devices\<addr>`) and global defaults: codec priority, SBC blocks/subbands/allocation/bitpool and AAC bitrate (sink key over the global default, restored at device start). Rate/channel preferences are retired and ignored; Windows selects PCM from all sink-supported driver formats, and the format of the last stream that ran is stored per sink only so the next device instance lists it first. VBR stays off.
2. Preference-aware `SbcConfig`/`AacConfig` selection with supported-value fallback. Done: `CodecPreferenceSbcBitpool` caps the selector's request and `CodecPreferenceAacBitrate` the AAC bitrate, both clamped to the sink's advertised range inside the shared selector, and `CodecTests` covers the clamps and that every bitpool still fits one RTP payload. A parameter change keeps the codec, so the signaling work item applies it in place: the encoder stops, SUSPEND brings the SEP to Open, RECONFIGURE carries the configuration the selector rebuilds from the selected SEP's advertised capabilities, and START resumes. A rejected command, or a sink-configured stream whose capabilities are unknown, falls back to close-and-rediscover. A stored block length, subband count or allocation pins the frame shape; one the sink does not advertise falls back to the selector's own order. An unadvertised forced codec is refused instead of stored. Each field stands on its own: there are no named combinations to keep in sync with a stored value.
3. Config IOCTLs and desktop UI (`OpenA2dpConfig.exe`) for device, codec and parameters. A codec change CLOSEs and rediscovers an active stream immediately (no sink reconnect); parameter changes that keep the codec use SUSPEND/RECONFIGURE/START. Done: the window lists the sinks (`tools/OpenA2dpConfig`), refreshes `GET_STATUS` on a timer, shows the session, the sink formats and the MTU ceiling, and stores codec settings through `SET_PREFERENCE`; it reads the preference back after every apply, so a refused value stays visible. Both tools print the report built by `tools/common/StatusReport`, so the window, its clipboard copy and `OpenA2dpCtl status` are the same text; `--verbose` and the window's Details box add every field of `Status`, `Preference` and `VersionInfo` with its hex value. `OpenA2dpCtl` remains the script path.
4. Multi-rate ACX: 16-bit PCM at 44.1/48 kHz, mono/stereo, intersected with sink SBC capabilities. The actual stream sets `PinSampleRate`/`PinChannels` for PCM/position math and negotiation. Windows opens the shared-mode stream with the first listed format and never queries `PROPOSEDATAFORMAT2`, so the proposed format leads the list instead of a fixed mode format; hardware verification remains. See [Codec settings](Codec-Settings.md) for default selection and diagnostic distinctions.
5. M6: finish UI and clean install/uninstall restoring `BthA2dp.sys`.
